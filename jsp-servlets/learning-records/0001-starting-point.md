# Starting point: new to Java, HTTP, and SQL

On 2026-10-04 the learner said they are new to Java and that both HTTP and SQL are new to them. They need to explain Project 5 (an AI-drafted JSP/Servlet/JDBC login app) to Ithena, who are assessing them for a role, in a live walkthrough with Q&A within about two weeks.

**Implications:** Teach HTTP (requests, methods, redirects, cookies), SQL, and Java syntax just in time, always through the Project 5 files rather than toy examples. Do not assume they can read a Java method signature, an annotation, or a `try/catch` yet. Prioritise explanation and design reasoning over writing new code, since the format is a walkthrough, not live coding.
