The layers

Each colour marks one layer of the app, and the lessons use the same colours.

  • Browser

    Sends HTTP requests and shows the HTML that comes back.

  • Tomcat

    The servlet container. It listens on port 8080, picks the servlet for each URL, and runs the JSPs.

  • Servlets and filters

    Java classes in web/ that receive requests and decide what happens. The controllers.

  • JSPs

    HTML templates in WEB-INF/views/ that produce each page. The views.

  • JDBC and the database

    UserDao sends SQL through JDBC to the users table in an H2 database.

A login, in five steps

  1. The browser sends POST /jsp-login/loginwith the userId and password fields from the form.
  2. Tomcat calls LoginServlet.doPostbecause @WebServlet("/login") claims that URL and the method is POST.
  3. UserDao fetches the stored password hashwith SELECT password_hash FROM users WHERE user_id = ? over JDBC.
  4. LoginServlet checks the passwordWrong: it forwards to login.jsp with an error. Right: it stores the User ID in a new session and redirects to /home.
  5. The browser gets the responseEither the login page with the error, or a redirect that makes it request GET /home.

Every URL

All URLs start with the context path /jsp-login. SecurityHeadersFilter runs first on every request and adds browser security headers.

/loginLoginServletShows login.jsp, or sends a logged-in user to /homeChecks the password. Wrong: login.jsp with an error. Right: new session, redirect to /home
/registerRegisterServletShows register.jspValidates the form, checks for a taken User ID or email, saves the user with a hashed password and photo, redirects to /registered

/homeAuthFilter, then HomeServletLoads the user and shows home.jsp: today's date, welcome, photo—
/photoAuthFilter, then PhotoServletSends the logged-in user's photo bytes from the database—
/logoutLogoutServletRedirects to /homeEnds the session, redirects to /login?loggedOut

AuthFilter sends anyone without a logged-in session to /login?required. Any 404, 405, or 500 error shows error.jsp (set in web.xml).

Run it

From a checkout of the feat/project-5-jsp-login branch, in Project_5_JSP_Login/. The project needs JDK 17; this Mac's default java is 11, so point Maven at 17:

JAVA_HOME=$(/usr/libexec/java_home -v 17) ./mvnw package cargo:run

Then open localhost:8080/jsp-login. Stop with Ctrl+C. The database file lives in ~/.jsp-login/.
